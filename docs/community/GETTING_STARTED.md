## TL;DR

```bash
curl -fsSL https://memdoor.ai/install.sh | bash
export OPEN_ROUTER_API_KEY=sk-or-...
cd your-project && memdoor tui
```

Install, then run the agent in your project on your own key, any provider's (`memdoor connect`).

For every command and flag, see **[reference/CLI.md](../reference/CLI.md)**.
