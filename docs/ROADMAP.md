# Roadmap: the quarter

Memdoor is the CLI coding agent. Team Mode: cheap models, frontier results,
on your machine. The runs are published. The terminal, a shell, CI,
cron, an editor and a phone are doors onto it.

Features are issues. The label `now` is what is being built; `next` is what
follows when the evidence asks for it. This page is the quarter: what the
quarter is for and how it is judged.

## Q4 2026 (2 November to 31 December)

**For:** the people who run local models use the harness and come back.

Decided on 2026-11-02 after the LiveCodeBench Hard thread. The harness is the
product. The other surfaces are kept and not extended until a user asks.

**Judged on 31 December by:**

1. The result page shows team-solve on Qwen3.8-27B on a 24 GB card and on a
   32 GB Mac, each run published, with the score and the hours.
2. The README's first screen and the getting-started page open on
   `memdoor connect local` and one workflow command, and a stranger's first
   run is on the result page.
3. The lean review passes on a model that refuses thinking off. Met on
   2026-11-05: this repo's review check runs it on glm-5.3-flash for every
   pull request, the refusal asked again with effort low (#25).

**Not this quarter:** a hosted box, extensions to SSH peers and the editor
door, voice and messaging channels.

## Changing the plan

The quarter changes at its end, or earlier on evidence: a user asked, a run
showed it, a number moved. The issue that carries the evidence is linked
from the change.
