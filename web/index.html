Memdoor: an AI coding agent in your terminal, on your own API key

Memdoor reads your files, writes patches, runs the build and fixes what it broke, on your own account at OpenRouter, Anthropic, OpenAI, Gemini, DeepSeek, Baseten, Groq or xAI. A decision model in front of the chat model keeps what it reads to what the task needs: 49% fewer input tokens on a question about a codebase, 26% fewer on an edit, measured over twenty paired runs with every answer right.

Describe the steps and it builds a workflow: one task file per step, run as a graph. Independent steps run in parallel, a step is done when its file exists or its command passes, a gate waits for your approval, and a failed run resumes at the failed step. Workflows run by hand or on your local cron.

Free: the agent, the decision model and workflows. Pro, $10 a month: remote control from your phone (the page is your terminal, end-to-end encrypted) and workflow state kept on memdoor.ai so a workflow can wait on what another produced, from any machine. Every model call is on your own key.

Install (macOS, Linux, Windows)

curl -fsSL https://memdoor.ai/install.sh | bash
export OPEN_ROUTER_API_KEY=sk-or-...
cd your-project && memdoor tui

Open source under Apache 2.0: github.com/guregodevo/memdoor. One binary, no Docker, no Python. Read the installer. Windows: irm https://memdoor.ai/install.ps1 | iex.
