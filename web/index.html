Memdoor: one small model can't. A team beats a frontier model.

One CLI binary for macOS, Linux and Windows, used locally or over SSH on another machine. No Docker or Python required. Start work from a terminal, your IDE or phone, or from a shell script, CI or a schedule, and finish it from any of those, on your gateway.

Token optimization: a decision model filters search hits, file sections and logs, selects the tools the turn needs and stops stalled turns. Across 44 runs (22 pairs), all tasks passed with decisions off and on; one codebase question used 74% fewer input tokens, while edits and fixes showed no saving. Savings depend on the task.

No key at all: memdoor connect local finds janis on this machine, or Ollama, llama.cpp, vLLM, LM Studio, and nothing leaves it. How to run it on an open-weight model.

Headless-first CLI: memdoor run takes a prompt, writes an answer to stdout and returns an exit code reflecting its checks. Resume the same conversation interactively when needed.

Result: five Qwen3.8-27B agents, run as a Memdoor workflow that rebuilds GVS5H's harness with the authors' exact prompts, scored a mean of 9.8 of 10 on the first ten problems of their LiveCodeBench Hard list over five passes, against 9.6 for the authors' harness and 8.0 for Fable 5 in a single call; on these ten the authors' own data put Fable 5 at 80 and their harness at 96, the gap the workflow reproduces (across their full 100: 92.4 and 90.4). All 50 runs are published. The result · the Hacker News thread.

Describe the steps and it builds a workflow: one task file per step, run as a graph. Independent steps run in parallel, a step is done when its file exists or its command passes, a gate waits for your approval, and a failed run resumes at the failed step. Workflows run by hand or on your local cron.

Free and open source (Apache-2.0): the agent, the decision model, workflows and remote control from your phone on your own gateway. Every model call is on your key. Enterprise, set up and supported by us: hello@memdoor.ai.

Install (macOS, Linux, Windows)

curl -fsSL https://memdoor.ai/install.sh | bash
export OPEN_ROUTER_API_KEY=sk-or-...
cd your-project && memdoor
