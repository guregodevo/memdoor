# team-solve-v2

Solves a programming problem with a team of fresh contexts, the method of [GVS5H](https://github.com/slee-persis/GVS5H) (five Qwen3.8-27B models match Fable 5 on LiveCodeBench Hard), and fails the run when the samples do not pass.

`plan` reads `task.md` and writes `plan.md` and `notes.md`, the ledger. `ideate-a` and `ideate-b`, in parallel, each add a proposal to the ledger. `solve` writes `solution.py`, a program that reads stdin. `test` runs every `tests/N.in` through it and diffs against `tests/N.out`. `review` reads the result and records what to fix; `repair` is one fresh worker on that; `verify` runs the samples again and fails the run if any differs. Each role starts from nothing and reads only the files on disk, so no context carries another role's dead ends. Rebuilt byte for byte with the authors' prompts and loop on Qwen3.8-27B, their harness scored 9.8 of 10 over five passes on the first ten problems of their list, against 9.6 for their own harness and 8.0 for Fable 5 alone, every run published: [examples/workflows/team-solve-v2](../../examples/workflows/team-solve-v2/).

Run it in a folder with `task.md` and paired `tests/N.in` / `tests/N.out` files: `memdoor workflow run team-solve-v2 --wait`, exit 0 when every sample passes. In an empty folder, `problem` copies the sample problem in first (`task.md`, five samples), so the first run needs nothing. It leaves `plan.md`, `notes.md`, `solution.py`, `review.md` and the test logs. Needs Python 3, bash and diff.

The steps name no model: whatever is pinned answers, a local one included. With no key, `memdoor connect local` connects Ollama, llama.cpp, vLLM or LM Studio on this machine ([how](https://memdoor.ai/docs/providers#a-local-runtime-no-key)). Ollama reads a prompt through a 4,096-token window unless told otherwise, and a role's prompt is longer than that: start it with `OLLAMA_CONTEXT_LENGTH=32768`, or make a tag with `PARAMETER num_ctx 32768` and pin that one. A hard problem is about 300K output tokens through the loop, an hour or more on a home machine, as a background job.
