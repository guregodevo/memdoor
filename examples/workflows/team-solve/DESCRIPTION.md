team-solve uses fresh agent tasks coordinated through the on-disk ledger: a planner reads task.md and writes plan.md; two parallel ideators append independent proposals to notes.md; a solver writes solution.py; a manager reviews captured sample-test results and records any necessary correction for one fresh repair worker. It needs Python 3, bash, diff, task.md, and paired tests/*.in and tests/*.out. Run it with /workflow:team-solve. It leaves plan.md, notes.md, solution.py, review.md, test-output.log, test-status.txt, and final-test-output.log. The first command captures the strict test runner's failure status without blocking the manager; the final command reruns all samples and fails the workflow if any differ. There is at most one repair round, no human gate, and no file-existence targets that could silently reuse a previous run. Parallel ideators update distinct ledger anchors without replacing the shared file; all inter-agent context is read from disk.
