### PLAN
Model each person as an interval \([l,r]\) with sign “min” if \(S_i<T_i\) and “max” if \(S_i>T_i\); a set of people is feasible iff the equality components induced by their endpoints can be topologically ordered, and this is equivalent to the set containing no conflicting pair. A conflicting pair is exactly: two same-sign intervals that strictly cross; two intervals sharing a left or right endpoint with different other endpoints; or the same interval with opposite signs. For every person \(j\), compute \(p[j]\), the largest index \(i<j\) that forms a conflicting pair with \(j\); then a query \([L,R]\) is Yes iff \(\max_{j\in[L,R]} p[j] < L\). Endpoint/identical conflicts are found by grouping indices by left and right endpoints and scanning in input order; same-sign crossing conflicts are found by a CDQ divide-and-conquer on the index order, using two 1D sweeps and a rollbackable segment tree for range maximum. Finally, answer the \(Q\) interval queries with a range-maximum structure over \(p\).

### TASKS
- Parse and normalize the input: store \(l[i]=\min(S_i,T_i)\), \(r[i]=\max(S_i,T_i)\), and \(sign[i]=+1\) for \(S_i<T_i\), \(-1\) for \(S_i>T_i\); initialize \(p[1..M]=0\).
- Compute endpoint and identical conflicts: for each group with the same \(l\) and for each group with the same \(r\), scan indices in increasing order and update \(p[j]\) with the maximum earlier \(i\) that has a different other endpoint or, for the same other endpoint, the opposite sign, maintaining top two distinct other endpoints and latest opposite sign.
- For each sign separately, run CDQ on the subsequence of that sign: in each merge, process left-to-right crossing pairs by (a) sweeping left by \(l\) and right by \(l\) to catch \(l_i<l_j<r_i<r_j\), and (b) sweeping left by \(r\) and right by \(r\) to catch \(l_j<l_i<r_j<r_i\); use a rollbackable/timestamp-cleared segment tree over town coordinates storing maximum index to update \(p[j]\).
- Build an iterative segment tree or sparse table for range maximum over \(p\), and answer each query \([L,R]\) by printing Yes if the maximum \(p\) in \([L,R]\) is less than \(L\), otherwise No.
- Validate the pairwise characterization and implementation with small brute-force tests (build the component constraint graph and check acyclicity) and verify performance/memory for the maximum constraints.
