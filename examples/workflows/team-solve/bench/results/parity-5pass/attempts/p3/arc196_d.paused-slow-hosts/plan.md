Represent each person as a signed interval \([l_i,r_i]\) (\(l_i=\min(S_i,T_i)\), \(r_i=\max(S_i,T_i)\)), where sign \(+\) means interior values must be above the endpoints and sign \(-\) means below. A set is feasible iff it has no bad pair: intervals sharing the same left or same right endpoint, or same-sign intervals that strictly cross; this follows because same-sign intervals must be laminar and opposite-sign overlaps only force \(+\) endpoint values below \(-\) endpoint values, yielding an acyclic partial order. Thus for each \(i\) compute the smallest \(j>i\) that is bad with \(i\), and a query \([L,R]\) is Yes iff \(R < \text{suffix\_min}_{i\ge L} \text{earliest}[i]\). Same-endpoint earliest partners are obtained by scanning \(i\) backwards with last seen left and right endpoint arrays. Same-sign crossing earliest partners are obtained in two passes (original and reversed coordinates) by processing \(j\) increasing and maintaining, per sign, a segment tree over \(r\) with per-\(r\) min-heaps of \(l\) for active earlier intervals; the query removes all active \(i\) with \(l_i<l_j<r_i<r_j\) and assigns \(j\). Combine the two crossing passes with same-endpoint answers, build the suffix minima, and answer the \(Q\) queries.
