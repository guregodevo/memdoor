Convert each person to a prefix-vertex interval [L_i,R_i] (L=min(S,T)-1, R=max(S,T)-1) and a sign (+ for S<T, - for S>T); the stamina conditions become P_{L_i}=P_{R_i} and all internal P_v strictly greater (for +) or smaller (for -) than that endpoint value. A set of people is infeasible exactly when it contains a bad pair: same-sign intervals that cross, intervals having the same left endpoint or the same right endpoint (with different other endpoint), or the same interval with opposite signs. Thus a query [L,R] is No iff there is a bad pair (i,j) with L<=i<j<=R, so it suffices to know for each i the smallest later j that forms a bad pair. Shared-endpoint bad pairs are found by the next occurrence of the same L or same R in input order. Same-sign crossing bad pairs are found by processing each sign and each orientation with a segment tree over one endpoint coordinate that stores the maximum of the other endpoint, reporting and deleting all previous intervals in the crossing rectangle. Take suffix minima of these earliest bad partners and answer each query by checking whether the suffix minimum is <= R.
