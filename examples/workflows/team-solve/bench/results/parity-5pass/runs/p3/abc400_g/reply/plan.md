### PLAN
Reformulate the problem as selecting 2K cakes and coloring each selected cake with one of the three attributes, requiring each color to be used an even number of times; the total value is the sum of the chosen attribute values, and this equals the original maximum because each pair can be assigned to the attribute attaining its max. Introduce a penalty P per pair and use WQS/Aliens binary search: multiply all attribute values by 2 and, in a DP, subtract P from every selected cake so that the pair penalty is integral. For a fixed P, an 8-state DP over the parity of the X/Y/Z counts computes the maximum adjusted value and, among optimal solutions, the maximum number of selected cakes by skipping a cake or assigning it to one of the three colors. The optimal value as a function of the number of pairs is concave (maximum-weight matching cardinality property, equivalently M-concavity of the parity-assignment family), so the largest P for which the DP returns at least 2K selected cakes identifies the target cardinality. If V is the adjusted value at that P, the answer is (V + P*2K)//2, giving O(31·N·24) time over all tests.

### TASKS
- Prove the reduction to even-parity 3-color assignment and the concavity needed for WQS; fix the integer scaling (values ×2, penalty P per selected cake) and the answer reconstruction formula.
- Implement the fixed-penalty DP: 8 parity states, initial state 0 with value 0/count 0, transitions skip or assign to X/Y/Z toggling the corresponding bit and adding 2*value-P; keep the maximum selected count whenever adjusted values tie.
- Implement binary search for each test case over P in [0, 2*10^9+1], using the DP's max selected count >= 2K as the feasibility condition, and store the DP value at the final low.
- Optimize for the total N limit (sum 1e5): precompute scaled triples, unroll or tightly loop the 8-state DP, use fast input, and use a large negative sentinel for unreachable states.
- Validate on the samples and edge cases such as all zero values, N odd, K=N//2, tied attribute values, and maximum 1e9 values; print one answer per test case.
