- **Reduction:** Strong connectivity is equivalent to every nonempty proper prefix receiving at least one added edge from outside. Path edges only go forward, so a prefix has an incoming added edge iff some black inside it is paired to a white outside it. Vertex 1 must be black and vertex 2N white; otherwise the answer is 0.
- **Prefix events:** For each B-run start, let b be the number of whites before it and m the number of blacks before it. If m > 0 and b >= m, keep event (b, m). For a fixed m, b is maximal just before the next black, so avoiding this event avoids all earlier prefixes with the same m. Inside a B-run, larger m at the same b is dominated by the run-start event.
- **Permutation model:** Pairings are permutations assigning white ranks to black ranks. Event (b, m) means the first m black ranks are all assigned white ranks <= b. Strong connectivity means avoiding all kept events.
- **Inclusion-exclusion recurrence:** With events sorted by increasing b and m, define g_i by g_i = -(fact[b_i] + sum_{j<i} g_j fact[b_i - m_j]) * invfact[b_i - m_i] mod. The final answer is fact[N] + sum_i g_i fact[N - m_i]. This follows from counting intersections of step-shaped forbidden conditions and factoring by the largest selected event.
- **CDQ online convolution:** add[i] stores sum_{j<i} g_j fact[b_i - m_j]. cdq(l, r) solves the left half, adds left-to-right contributions, then solves the right half. Leaves compute g. For NTT cross, set ml = m[l], shift = b[mid] - m[mid-1], A[m_j - ml] = g_j, B[k] = fact[shift + k]. The coefficient at b_i - ml - shift gives the needed sum.
- **NTT fallback:** The fallback uses radix-2 DIF forward and DIT inverse without explicit bit-reversal. Forward output is bit-reversed, inverse expects that order and outputs natural order. Roots are precomputed up to the next power of two greater than 2N. Convolution uses direct multiplication for small products and NTT otherwise.
- **Atcoder convolution:** If available, atcoder.convolution.convolution is used directly; otherwise the manual fallback is defined. This keeps the file standalone while taking advantage of the ACL Python library when present.
- **Implementation choices:** Factorials and inverse factorials are precomputed up to N. K <= 2000 uses O(K^2) direct recurrence. Larger K uses CDQ with direct cross when left_len * right_len <= 8192, otherwise convolution. All add values are kept modulo.
- **Edge cases:** N=1 gives 1 for BW and 0 for WB. No events gives fact[N]. b = m is allowed and uses invfact[0]. All factorial indices remain in [0, N].
- **Validation:** Sample 1 gives 1, sample 2 returns 0 because the last character is B, and sample 3 direct recurrence over events (2,1), (3,2), (5,5), (6,6), (8,8) yields 240792.
