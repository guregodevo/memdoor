- **Edge variables:** Put one binary variable on each torus grid edge. No dead ends means the two sides of a shared edge use the same variable. For a cell, type A is equivalent to left xor right = 1 and top xor bottom = 1. Type B is equivalent to left xor right = 0, top xor bottom = 0, and left xor top = 1.
- **Row and column parity:** Xoring all horizontal equations around a row forces the number of A cells in that row to be even. Xoring vertical equations around a column forces the number of A cells in that column to be even. If any row or column parity is odd, the answer is 0. Rows are checked quickly with bytes.count before processing; columns are checked from the final col_pref array.
- **Free bits:** When a row has even A parity, all horizontal edges in that row are determined by one free bit, chosen as the left edge of column 0, plus the parity of A cells before each column. When a column has even A parity, all vertical edges in that column are determined by one free bit, chosen as the top edge of row 0, plus the parity of A cells before each row.
- **B-cell equations:** For a B cell at (i, j), the condition left xor top = 1 becomes row_bit_i xor col_bit_j = 1 xor row_prefix_before_j xor col_prefix_before_i. A cells add no cross-row/column equation beyond the parity conditions.
- **Counting:** There are H + W variables and one labeled XOR equation for each B cell. A parity union-find checks consistency and counts connected components. If consistent, the number of assignments is 2^(number of components), including isolated row and column variables, modulo 998244353.
- **Implementation details:** Read all input tokens at once. The union-find parent array stores negative sizes for roots; parity[x] is the xor from x to its parent. The find operation is inlined with path halving and returns the root and xor-to-root. Union by size attaches the smaller root to the larger root, and the attached root parity is px xor py xor label. col_pref[j] stores the parity of A cells above the current row, and row_pref stores the parity of A cells left of the current column. Once a case becomes invalid, remaining row tokens for that case are skipped.
- **Complexity:** O(sum HW alpha(H + W)) time and O(H + W + input) memory per case, well within the 1e6 total cell limit.
- **Sample check:** The three sample cases evaluate to 2, 0, and 2.
