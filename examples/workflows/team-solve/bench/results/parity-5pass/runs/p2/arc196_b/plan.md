Represent each grid edge by a binary variable that is 1 if a tile endpoint lies on that edge; the no-dead-end condition forces the two variables on opposite sides of the same edge to be equal. For a cell, type A means its left/right variables differ and its top/bottom variables differ, while type B means left/right equal, top/bottom equal, and right/bottom differ, so all local constraints are XOR equations over GF(2). The horizontal equations imply each row must contain an even number of A cells, and the vertical equations imply each column must contain an even number of A cells; otherwise the answer is 0. When these parities hold, all horizontal edge variables are determined by one free bit per row and all vertical edge variables by one free bit per column. Each B cell then gives one XOR constraint between its row bit and column bit, with label equal to the row prefix of A's before that column XOR the column prefix of A's before that row XOR 1. Count the assignments of these H+W bits satisfying the bipartite XOR constraints with a parity DSU; if consistent, the number is 2^{components} modulo 998244353.
