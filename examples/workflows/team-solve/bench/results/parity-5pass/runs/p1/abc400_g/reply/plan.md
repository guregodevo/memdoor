### PLAN
Reduce the problem to choosing 2K cakes and assigning each chosen cake to one of the three attributes, requiring an even number of chosen cakes for each attribute; the maximum assigned sum equals the maximum total pair price. Solve the unconstrained version by taking the 2K cakes with largest max-attribute value and assigning each to a maximizing attribute, giving a baseline total and a parity mask. A parity-exchange argument shows that an optimal parity-feasible assignment can be obtained from this baseline by at most two local changes, each either recoloring a selected cake or swapping a selected cake with an unselected one. Therefore the answer is the baseline total minus the minimum loss needed to make the parity mask zero using 0, 1, or 2 such changes. Precompute the cheapest recolor and swap operations for each parity mask, plus top-two selected and unselected values to enforce disjointness, and evaluate the constant number of two-operation combinations.

### TASKS
- For each test case, compute b_i = max(X_i,Y_i,Z_i) and a base color attaining it, sort cakes by b_i descending, take the first 2K as selected, and compute the baseline sum and the parity mask of selected base colors.
- Build selected-side tables: for each base color, the two smallest b_i among selected cakes; for each of the three nonzero parity masks, the two cheapest recolor operations (change a selected cake to another color) with their selected-cake ids.
- Build unselected-side tables: for each color, the two largest attribute values among unselected cakes with ids; for each nonzero parity mask, the two cheapest swap operations (remove a selected cake of one base color and add an unselected cake of another color) using the best unselected value, with selected-cake ids.
- If the baseline parity mask is nonzero, compute the minimum loss to make it zero by trying the best one operation and the four two-operation combinations of the other two masks (recolor+recolor, recolor+swap, swap+recolor, swap+swap), enforcing distinct selected cakes and, for two swaps, distinct selected and unselected cakes via the top-two tables.
- Output baseline sum minus the minimum loss for every test case, using 64-bit integers and O(N log N) total time over all test cases.
