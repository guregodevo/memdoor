### PLAN
Transform each person into a constraint on prefix sums P_0,...,P_{N-1}: for S_i<T_i use interval [l_i,r_i]=[S_i-1,T_i-1] and sign +, meaning P_{l_i}=P_{r_i} and every P_x with l_i<x<r_i is larger; for S_i>T_i use [T_i-1,S_i-1] and sign -, meaning interior P_x are smaller. A set of such constraints is feasible iff it contains no bad pair: two constraints sharing a left endpoint or a right endpoint, or two same-sign constraints with strictly crossing intervals. Hence a query [L,R] is infeasible exactly when it contains a bad pair. For each index j compute f[j]=max{i<j : (i,j) is a bad pair}; then pref[R]=max_{j<=R} f[j] and the answer is Yes iff L>pref[R]. The endpoint part is a simple last-occurrence scan, while the same-sign crossing part is computed by CDQ over the index order with a 1D segment tree over coordinates, run for each sign and again on mirrored coordinates.

### TASKS
- Convert all persons to arrays l[1..M], r[1..M], sign[1..M] (sign + for S_i<T_i, - otherwise), and compute endpoint bad pairs: scan j=1..M keeping last_l and last_r, set f[j]=max(f[j], last_l[l_j], last_r[r_j]), then update last_l/last_r.
- Implement a reusable timestamped segment tree over coordinates 0..N-1 that supports point max-update and inclusive range max-query; use a global token per CDQ cross so old updates are ignored without clearing.
- Implement a CDQ routine for a fixed sign and fixed coordinate arrays: it takes the list of original indices for that sign, splits by their position in that list, recursively returns the sub-list sorted by l, and in the cross step sweeps right-half indices by increasing l, adds left-half indices with l_i<l_j to the segment tree at r_i, queries max over r in [l_j+1, r_j-1], and updates f[j]; finally merge the two sorted sub-lists by l.
- Run this CDQ for the plus and minus subsequences on original (l,r), and again on mirrored coordinates l'=N-1-r, r'=N-1-l, taking the maximum into f[j] for all crossing bad pairs.
- Build pref[j]=max(pref[j-1], f[j]), answer each query [L,R] with Yes iff L>pref[R], and stress-test on samples plus small random instances against a generic difference-constraints cycle check (or bounded P enumeration), including touching endpoints and identical opposite intervals.
