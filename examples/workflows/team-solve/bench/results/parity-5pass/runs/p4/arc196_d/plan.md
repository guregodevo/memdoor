Transform each person into a constraint on prefix sums P_0,...,P_{N-1}: for S_i<T_i use interval [l_i,r_i]=[S_i-1,T_i-1] and sign +, meaning P_{l_i}=P_{r_i} and every P_x with l_i<x<r_i is larger; for S_i>T_i use [T_i-1,S_i-1] and sign -, meaning interior P_x are smaller. A set of such constraints is feasible iff it contains no bad pair: two constraints sharing a left endpoint or a right endpoint, or two same-sign constraints with strictly crossing intervals. Hence a query [L,R] is infeasible exactly when it contains a bad pair. For each index j compute f[j]=max{i<j : (i,j) is a bad pair}; then pref[R]=max_{j<=R} f[j] and the answer is Yes iff L>pref[R]. The endpoint part is a simple last-occurrence scan, while the same-sign crossing part is computed by CDQ over the index order with a 1D segment tree over coordinates, run for each sign and again on mirrored coordinates.
