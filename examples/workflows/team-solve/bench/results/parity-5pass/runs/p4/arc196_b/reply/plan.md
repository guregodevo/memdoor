### PLAN
Model the presence of an endpoint on each grid edge as a binary variable and translate each tile type into XOR equations: an A cell forces its left/right endpoints to differ and its top/bottom endpoints to differ, while a B cell forces its left/right endpoints to be equal, its top/bottom endpoints to be equal, and the horizontal pair value to differ from the vertical pair value. The horizontal equations determine all horizontal edge variables in a row from one row base variable, and they are consistent exactly when the row contains an even number of A's; the vertical equations similarly require every column to contain an even number of A's. If any row or column parity is odd, the answer is 0. Otherwise, each B cell induces one parity constraint between its row base variable and its column base variable, with a label computed from prefix XORs of A's in that row and column. Use a parity DSU on H row nodes and W column nodes to check consistency and count connected components; the answer is 2^{components} modulo 998244353.

### TASKS
- For each test case, read the grid and convert characters to bits (A=1, B=0); compute the XOR of bits in each row and each column, and mark the case impossible if any row or column XOR is 1.
- Implement a parity DSU that stores for each node its parent and XOR-to-parent, supports find(x) returning (root, xor_to_root), and unite(u, v, w) enforcing value[u] XOR value[v] = w, detecting contradictions and maintaining the number of components.
- If the case is possible, create H+W DSU nodes: row bases 0..H-1 and column bases H..H+W-1; initialize a length-W array col_pref to 0, representing the XOR of A-bits in rows already processed.
- For each row i from 0 to H-1, scan columns j from W-1 down to 0 while maintaining hpref as the XOR of A-bits to the right of j; when the cell is B, unite row i with column H+j using w = 1 XOR hpref XOR col_pref[j] (col_pref[j] is the XOR of A-bits in earlier rows, equal to the needed top-edge prefix because column parities are zero), then XOR the current A-bit into hpref and col_pref[j].
- After processing, output 0 if the case was impossible or a DSU contradiction occurred; otherwise output pow(2, component_count, 998244353). Use fast buffered input and compact arrays to stay within the total 10^6 cell limit.
