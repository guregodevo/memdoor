- **Endpoint condition:** Strong connectivity is impossible unless vertex 1 is black and vertex 2N is white. If not, answer is immediately 0.
- **Cut characterization:** With path edges i -> i+1, strong connectivity is equivalent to every proper prefix having at least one added edge from the suffix to the prefix. For a prefix containing c black vertices and w white vertices, the bad event is that all first c black vertices are paired with whites inside that prefix.
- **Event reduction:** For each c, only the maximum w among prefixes with c black vertices matters. This maximum is the number of whites before black c+1, denoted R[c]. If R[c] < c, the bad event is impossible. If R[c] is unchanged for larger c, the later event is implied by the earlier one, so only record increases with R[c] >= c are kept.
- **Inclusion-exclusion recurrence:** Let kept events be (c_i, r_i), increasing. Let A[i] be the signed inclusion-exclusion coefficient for subsets whose maximum kept index is i. Then  
  `A[i] = -(fact[r_i] + sum_{j<i} A[j] * fact[r_i - c_j]) / fact[r_i - c_i]`.  
  The answer is `fact[N] + sum_i A[i] * fact[N - c_i]`.
- **Combinatorial meaning:** The recurrence comes from counting permutations satisfying a set of prefix constraints. For a subset of events, the allowed board is Ferrers-shaped, and the count factors into factorial ratios over the selected event sequence.
- **CDQ divide and conquer:** The recurrence is triangular. CDQ computes contributions from the left half to the right half. For a node, left A-values are placed by their actual c-coordinate and convolved with a factorial segment to update all right-side query sums.
- **Convolution indexing:** For a node [l, right), with left c-range [c_l, c_mid] and right r-range [r_mid, r_last], set `min_diff = r_mid - c_mid` and `max_diff = r_last - c_l`. Convolve left A at offsets `c_j - c_l` with `fact[min_diff : max_diff+1]`. For right event i, the needed coefficient is at index `r_i - c_l - min_diff`.
- **NTT implementation:** Uses DIF forward and DIT inverse transforms with precomputed twiddle factors for all powers of two up to the maximum needed transform size. No bit-reversal permutation is needed because the forward output and inverse input are consistently bit-reversed.
- **Transform size bound:** The maximum convolution length needed is bounded by `(c_max - c_0 + 1) + (r_max - c_0 + 1) + 5`, which is at most about 2N. Roots are precomputed only up to that power of two.
- **Direct fallback:** For small M or small CDQ node products, direct O(left_len * right_len) updates are faster. The top-level solver chooses direct for M up to 4000, and adaptively up to 6000 when the coordinate span makes NTT less attractive. Inside CDQ, small node products are handled directly, with an additional cost-based direct fallback for unbalanced nodes.
