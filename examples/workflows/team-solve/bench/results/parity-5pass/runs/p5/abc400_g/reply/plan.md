### PLAN
Model a solution as choosing 2K cakes and coloring each chosen cake by one of the three attributes, with each color used an even number of times; the score is the sum of the colored attribute on each cake. Ignoring parity, the optimum is the top 2K cakes by M_i = max(X_i, Y_i, Z_i), each colored by a maximizing attribute. If the resulting color parities are all even, this baseline is optimal; otherwise an exchange argument shows an optimal parity-feasible solution is obtained by at most two operations: recolor one selected cake or swap one selected cake with one unselected cake. Compute the minimum loss among one or two such operations using top-two candidates per color and subtract it from the baseline total.

### TASKS
- Parse all test cases; for each, compute M_i, sort cakes by M_i descending, mark the first S = 2K cakes as selected, compute baseline total W0, assign each selected cake one maximizing attribute as its initial color, and compute parity p by XORing color codes X=1, Y=2, Z=3 over selected cakes.
- Build top-two candidate tables: selected_minM[color] (two smallest M among selected cakes with that initial color), selected_reassign[color][target] (two smallest M_i - value_i[target] for selected initial color color and target != color), and unselected_max[target] (two largest value_i[target] among unselected cakes).
- Implement small helpers: pair_min(t1, t2) returning the minimum sum of one candidate from each top-two list with different cake ids, pair_max(t1, t2) returning the maximum sum with different ids, and forms[parity] listing ordered (old_color, new_color) pairs whose XOR is that parity.
- If p != 0, compute min_loss by checking one reassignment or one swap with parity p, then for every q in {1,2,3} with r = p ^ q nonzero, check two-operation combinations R+R, R+S, S+R, and S+S using the tables, enforcing distinct selected/unselected ids via pair_min/pair_max and using INF for infeasible cases.
- Output W0 - min_loss for each test case; use fast input and ensure total complexity O(N log N) over all test cases.
