### PLAN
Convert each person to a prefix interval (l, r) and sign: l = min(S, T) - 1, r = max(S, T) - 1, sign + if S < T and - if S > T. A set of people is feasible iff no two converted intervals form a bad pair: identical interval with opposite signs, same left endpoint with different right endpoints, same right endpoint with different left endpoints, or crossing intervals with the same sign. This follows because contracting equal endpoint prefix nodes turns the requirements into strict inequalities, and the resulting directed graph is acyclic exactly when no such pair exists. For queries, let bad[j] be the largest index i < j that forms a bad pair with j; then [L, R] is feasible iff max_{j ≤ R} bad[j] < L. Compute bad[j] with hash maps for the endpoint/identical cases and with an offline CDQ divide-and-conquer plus range-max sweeps for same-sign crossing pairs. Finally answer all queries in O(1) using prefix maxima of bad.

### TASKS
- Transform all M people into arrays l, r, sign using l = min(S, T) - 1, r = max(S, T) - 1, preserving their original indices.
- Initialize bad[j] = 0 and fill non-crossing bad pairs by scanning j = 1..M: use a dictionary keyed by (l, r, sign) for identical opposite signs, and for each l and each r maintain the latest two indices with distinct other endpoints to detect same-l-different-r and same-r-different-l.
- For each sign separately, compute same-sign crossing predecessors with CDQ over the index-ordered list: in each merge, sweep left intervals by r and right queries by r, using a segment tree for range-max update on (l_i, r_i) and point query at l_j; repeat on reversed coordinates (N - 1 - r, N - 1 - l) to cover the other crossing direction, updating bad[j] with the maximum left index found.
- Build pref[R] = max(pref[R - 1], bad[R]) and for each query print Yes if pref[R] < L, else No.
- Verify edge cases (adjacent intervals sharing an endpoint are not bad, identical same-sign intervals are not bad, strict coordinate ranges) and ensure the implementation runs in O((M + Q) log^2 M) or O(M log^2 N) time with O(M + N) memory.
