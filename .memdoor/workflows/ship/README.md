# ship

Ships what is committed and pushed: build, vet, the Go suite, the unused-code check and the web type check run in parallel; a red one blocks the rest. Then `push`, a gate for your yes, `make deploy`, and `verify` reads memdoor.ai back (the served `/dl/VERSION` is the newest tag, billing and the hosted state answer, the home page loads). The workflow never commits: commit first, then `/workflow:ship`; a dirty tree fails at `clean`. Needs `VPS_HOST` in the gateway's environment (`.envrc`) and the staticcheck binary at `$HOME/go/bin`. Leaves nothing in the project but the run's outputs. Approve the gate with `a` in `/workflow` or `memdoor workflow approve <run> approve`. A run is for a commit: `--partition $(git rev-parse --short HEAD)` resumes a stopped ship of the same commit.
